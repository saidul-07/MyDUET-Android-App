# MyDUET Android App

An unofficial Android application for **Dhaka University of Engineering & Technology (DUET)** students, built with **Java+Kotlin** and **Material Design 3**. The app provides quick access to academic information and campus services through a clean and modern user interface.

## Features

- 📚 Class Routine
- 📅 Weekly Routine
- 👤 Academic Profile
- 📢 University Notices
- 🚨 Emergency Contacts
- 📖 Library Information
- 🌙 Dark Mode Support
- 💾 Offline JSON-based Data

## Tech Stack

- Java+Kotlin
- Android Studio
- Material Design 3
- MVVM Architecture
- View Binding
- Jetpack DataStore
- Gson


Open the project in Android Studio, sync Gradle, and run the application.
